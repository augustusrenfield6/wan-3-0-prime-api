# Checked Argolink facts

Checked 2026-10-04 against the live model page `/en/models/wan-3-prime` and the local Argolink video contract.

- Canonical model ID: `wan-3-prime`.
- Endpoint: `POST /v1/videos/generations`; jobs are asynchronous.
- Output duration: 2–30 seconds; default 5.
- Resolutions: 480p, 720p, 1080p; default 720p.
- Ratios: adaptive, 16:9, 4:3, 1:1, 3:4, 9:16; frame workflows use adaptive.
- Prompt: required, maximum 20,000 characters.
- References: up to 10 images, 5 videos, 5 audio tracks, 20 total assets.
- Reference videos: combined duration limit of 15 seconds.
- Audio can be generated by default and disabled with `generate_audio: false`.
- One output is produced per request.
- `seed` and `watermark` are not advertised controls for this model.
- Failed and rejected jobs are not billed; completed output and reference-video seconds are billed according to the live page.

If these facts change, update this file, `docs/api-contract.md`, and the client together. Do not add a value merely because another model or an old integration used it.
